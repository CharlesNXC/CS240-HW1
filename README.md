# CS240 - Computer Organization

Assignment 1 - Converter and Pixel System

# What was required

1- Build an ASCII-to-decimal converter.
2- Build a number-base converter supporting binary, decimal, octal, and hexadecimal.
3- Write a program that reads an image and prints its pixel values.
4- Write a program that consumes pixel values and creates an image.
5- Test boundary cases, including zero, the largest supported unsigned value, and at least one negative two's-complement value.

## Deliverables

PDF including the following three items:

- GitHub Link
- all source code (including code and README)
- test evidence / screenshots / generated images / screenshots of GUI or CLI.

The main difficulties were the set-up of VSCode, to be able to execute different codes without issues. Some parts were also hard to understand in some codes.
